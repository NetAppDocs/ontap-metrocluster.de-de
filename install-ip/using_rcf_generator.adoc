= Informationen zur Verkabelung der MetroCluster IP-Switches
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vor Beginn der Verkabelung der MetroCluster IP Switches sollten die Anforderungen geprüft werden.

.Bevor Sie beginnen
Vor der Verkabelung der Switches sind folgende Punkte zu beachten:

* Für Standort A und Standort B kommt dieselbe Verkabelung zum Einsatz.
* Sie können die Switches nicht mit Ports unterschiedlicher Geschwindigkeit konfigurieren (z. B. eine Mischung aus 100-Gbit/s-Ports und 40-Gbit/s-Ports).
* Verfolgen Sie die MetroCluster-Portgruppe (MetroCluster 1, MetroCluster 2 usw.). Sie benötigen diese Informationen, wenn Sie das Tool RcfFileGenerator verwenden, wie später in diesem Konfigurationsverfahren beschrieben.
* Sie sollten alle Nodes auf die gleiche Weise verkabeln. Wenn für die Verkabelung der Nodes unterschiedliche Portkombinationsoptionen verfügbar sind, sollten alle Nodes die gleichen Port-Kombinationen verwenden. Beispiel: e1a auf Knoten 1 und e1a auf Knoten 2 sollten an einen Schalter angeschlossen werden. Gleichermaßen sollte der zweite Port beider Nodes an den zweiten Switch angeschlossen werden.



NOTE: Die Version der Referenzkonfigurationsdatei (RCF) unterscheidet sich von der Version des Tools RCFfilegenerator, das zum Generieren der Datei verwendet wurde. Beispielsweise lässt sich mit RCFfilegenerator v1.6c eine RCF der Version 2.00 generieren.



[[cabling-requirements-based-on-the-switch-type]]
== Verkabelungsanforderungen abhängig vom Schaltertyp

Nachfolgend sind die Verkabelungsanforderungen basierend auf dem jeweiligen Switch-Typ aufgeführt.



[[cisco-3132q-v]]
=== Cisco 3132Q-V

Wenn Sie den Switch für die MetroCluster FC zu IP Umstellung konfigurieren, können Port 5 oder Port 6 verwendet werden, um die lokalen Cluster-Schnittstellen des MetroCluster FC Knotens anzuschließen. Weitere Informationen zur Verkabelung dieser Konfiguration finden Sie in link:https://mysupport.netapp.com/site/tools/tool-eula/rcffilegenerator["RCfFileGenerator für MetroCluster-IP"^] und den generierten Verkabelungsdateien.



[[cisco-3232c-or-36-port-cisco-9336c]]
=== Cisco 3232C oder Cisco 9336C mit 36 Ports

* Wenn Sie den Switch für den Übergang von MetroCluster FC zu IP konfigurieren, können Sie Port 5, Port 6, Port 13 oder Port 14 verwenden, um die lokalen Cluster-Schnittstellen des MetroCluster FC Knotens anzuschließen. Weitere Informationen zur Verkabelung dieser Konfiguration finden Sie in link:https://mysupport.netapp.com/site/tools/tool-eula/rcffilegenerator["RCfFileGenerator für MetroCluster-IP"^] und den generierten Verkabelungsdateien.
* Für den 25G-Breakout-Modus von MetroCluster ISLs auf unterstützten Plattformen ist RCF Version v2.10 oder höher erforderlich.
* Für die Nutzung einer anderen Plattform als FAS8200 oder AFF A300 in der Gruppe "MetroCluster 4" werden ONTAP 9.13.1 oder höher und RCF Version 2.00 benötigt.




[[12-port-cisco-9336c-fx2]]
=== Cisco 9336C-FX2 mit 12 Ports

Der 12-Port-Switch Cisco 9336C-FX2 unterstützt nicht den Anschluss von NS224-Shelves an den MetroCluster-Switch.



[[36-port-cisco-9336c-fx2-switch-connecting-ns224-storage]]
=== 36-Port Cisco 9336C-FX2 Switch zum Verbinden von NS224 Storage

* Für das Verbinden von MetroCluster Konfigurationen mit einem oder zwei vier Nodes ist ONTAP 9.14.1 oder höher erforderlich.
* Wenn Sie einen Cisco 9336C-FX2 Switch mit NS224 Storage verkabeln, können Sie maximal zwei MetroCluster Konfigurationen oder DR-Gruppen haben. Mindestens eine MetroCluster Konfiguration oder DR-Gruppe muss NS224 Shelves mit dem MetroCluster Switch verbinden.
* Der RcfFileGenerator zeigt nur geeignete Plattformen an, wenn die erste Plattform ausgewählt ist.
* Wenn Sie eine reguläre MetroCluster Konfiguration erweitern, die keinen Switch-gebundenen NS224-Speicher unterstützt, und eine MetroCluster Konfiguration mit Switch-gebundenem NS224-Speicher hinzufügen möchten, beachten Sie die folgenden Informationen:
+
Im Tool RcfFileGenerator muss zuerst die Plattform ausgewählt werden, die switch-angebundenen NS224 Storage unterstützt, und anschließend die Plattform, die switch-angebundenen NS224 Storage nicht unterstützt.

+
Das bedeutet, dass Sie beim Generieren der RCF für Ihre neue Konfiguration die Plattformen im RcfFileGenerator Tool möglicherweise in der folgenden Reihenfolge auswählen müssen:

+
.. Im zweiten Dropdown-Feld erfolgt die Auswahl der Plattform, die switch-angebundenen NS224 Storage unterstützt.
.. Im ersten Dropdown-Feld die Plattform auswählen, die keinen Switch-gebundenen NS224 Storage unterstützt.






[[broadcom-bes-53248]]
=== Broadcom BES-53248

* Sie können die Switches nicht mit Remote-ISL-Ports unterschiedlicher Geschwindigkeit verwenden (z. B. ein 25-Gbit/s-Port, der an einen 10-Gbit/s-ISL-Port angeschlossen ist).
* Wenn Sie den Switch für den Übergang von MetroCluster FC zu IP konfigurieren, werden die folgenden Ports je nach gewählter Zielplattform verwendet:
+
[cols="75,25"]
|===
| Zielplattform | Port 


| FAS500f, AFF C250, ASA C250, AFF A250, ASA A250, FAS8300, AFF C400, ASA C400, AFF A400, ASA A400 oder FAS8700 Plattformen eingesetzt | Ports 1 bis 6, 10 Gbit/s 


| FAS8200 oder AFF A300 Plattformen | Ports 3 - 4 und 9 - 12, 10 Gbit/s 
|===
* Bei AFF A320 Systemen, die mit Broadcom BES-53248-Switches konfiguriert sind, werden möglicherweise nicht alle Funktionen unterstützt.
+
Jede Konfiguration oder Funktion, die erfordert, dass die lokalen Cluster-Verbindungen mit einem Switch verbunden sind, wird nicht unterstützt. Beispielsweise werden die folgenden Konfigurationen und Verfahren nicht unterstützt:

+
** MetroCluster Konfigurationen mit acht Nodes
** Der Wechsel von MetroCluster FC- zu MetroCluster IP-Konfigurationen
** Aktualisieren einer MetroCluster IP-Konfiguration mit vier Nodes (ONTAP 9.8 und höher)






[[nvidia-sn2100]]
=== NVIDIA SN2100

Für die Verbindung einer Konfiguration mit acht Knoten oder zweier Konfigurationen mit je vier Knoten MetroCluster sind ONTAP 9.14.1 oder höher und RCF Version 2.00 oder höher erforderlich.
